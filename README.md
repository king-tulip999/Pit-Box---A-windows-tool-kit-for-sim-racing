### iRacing Overlay

19 widgets: relative, standings, fuel and strategy, delta, radar, track map, inputs, tires, weather and more. Drag them around in the car with `Ctrl+Alt+E`, save layouts per car or track, or add any widget to OBS as a browser source.

- **Strategy:** fuel saving to skip a stop, undercut and overcut targets.
- **Practice goals, notes per corner, track limits and a race result card.**

## Getting started

1. **[Download](https://github.com/king-tulip999/Distro/releases/latest)** `Velocita.exe`, `Tecnica.exe` or both, and put them somewhere they can stay.
2. Run it. Windows will say it protected your PC: click **More info → Run anyway**.
3. Pick a few options on the setup screen and click **Get started**.

> [!TIP]
> Tecnica asks for administrator rights (sensors, fans and displays need them). Velocita doesn't.

> [!NOTE]
> Coming from Pit-Box? The first start copies your old settings, layouts and stats over. The old folder is left as it was.

## Questions

<details>
<summary><b>Why does Windows warn me?</b></summary>
<br>

The exes aren't code-signed (certificates cost money every year). To check your copy, compare `Get-FileHash Velocita.exe` in PowerShell with the `.sha256` file on the release page. The built-in updater checks every download's signature before installing it.
</details>

<details>
<summary><b>Is it safe with anti-cheat?</b></summary>
<br>

Nothing is injected into games: the overlays are separate click-through windows. They show over borderless and windowed games, not exclusive fullscreen.
</details>

<details>
<summary><b>What is PawnIO?</b></summary>
<br>

An optional free, signed driver Tecnica can use for CPU temperatures and motherboard fans (Settings → Hardware access → **Install PawnIO**). Without it everything else still works. Velocita never uses it.
</details>

<details>
<summary><b>What does it send online?</b></summary>
<br>

An update check against GitHub releases (if you leave it on), a small ping for Tecnica's network readout, and the GRR feed if you show that page. No accounts, no telemetry. Your stats stay on your PC.
</details>

<details>
<summary><b>What does it change on my PC?</b></summary>
<br>

Only what you set up. Velocita backs up iRacing files before changing them. Tecnica hands the fans back to the BIOS when it quits. If Tecnica is force-killed, fans stay at their last speed until it restarts or the PC reboots.
</details>

<details>
<summary><b>How do updates work?</b></summary>
<br>

Each app checks for updates in Settings → Application → About and updates. **Install and restart** downloads, verifies and swaps the exe. Your settings are kept.
</details>

<details>
<summary><b>How do I uninstall?</b></summary>
<br>

1. Turn off **Start with Windows** in each app.
2. Quit from the tray (in Tecnica, choose **Give fans back and quit** if fan control is on).
3. Delete the exes and `%APPDATA%\Velocita` / `%APPDATA%\Tecnica`.
4. If you installed PawnIO, remove it from Windows Settings → Apps.
</details>
